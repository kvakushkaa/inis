# DigiVault — Лабораторная работа №6

Стилизация React-приложения DigiVault (вариант 3, интернет-магазин цифровых товаров) с помощью **React Bootstrap**.

Цвета и шрифты DigiVault (Sora / Manrope, teal и amber) сохранены. Раскладка, кнопки, карточки и селектор количества собраны компонентами Bootstrap.

## Стек

- React + Vite
- Redux Toolkit / react-redux
- Bootstrap 5 + React Bootstrap

## Что заменено

| Было (кастом) | Стало |
|---------------|--------|
| CSS Grid каталога | `Container`, `Row`, `Col` |
| `button` | React Bootstrap `Button` |
| Селектор количества | `InputGroup` + `Form.Control` + `Button` |
| Карточка товара | `Card`, `Badge` |
| Шапка | `Navbar` |
| Корзина | `Card`, `ListGroup`, `Badge`, `Button` |
| Сообщение о действии | `Alert` |

Отступы и выравнивание задаются утилитами Bootstrap (`d-flex`, `gap-*`, `mb-*`, `py-*`, `g-4`). В CSS Modules остались только цвета, шрифты и форма карточек.

## Адаптивность

У каждой карточки свой `Col`: `xs={12}` (1 колонка), `md={6}` (2 колонки), `xl={3}` (3 карточки в ряд). Корзина — `Col xs={12} xl={3}`: на десктопе это четвёртая колонка, на меньшей ширине она уходит под каталог.

| Брейкпоинт | Товары | Корзина |
|------------|--------|---------|
| `xs` (мобильный) | 1 колонка | под каталогом |
| `md` (планшет, от 768px) | 2 колонки | под каталогом |
| `xl` (десктоп, от 1200px) | 3 колонки | четвёртая колонка справа |

## Запуск

```bash
npm install
npm run dev
```
